# PoseCertain — Uncertainty-Aware Spacecraft 6D Pose Estimation

> Spacecraft 6D pose estimation with MC Dropout uncertainty quantification for OOD detection on the SPEED dataset.

This project extends [UrsoNet](https://github.com/pedropro/UrsoNet) with **Bayesian uncertainty quantification** via MC Dropout, enabling the model to detect unreliable predictions on out-of-distribution (OOD) real-domain images.

---

## ✨ Key Contributions

- 🔵 **MC Dropout Inference** — 30-sample stochastic forward passes for uncertainty estimation
- 📊 **Orientation Uncertainty** — Predictive Entropy, Expected Entropy (Aleatoric), Mutual Information (Epistemic)
- 📍 **Location Uncertainty** — Gaussian NLL Loss with per-axis epistemic variance output
- 🌍 **OOD Detection** — Evaluated on real SPEED images; epistemic uncertainty correlates with pose error (r=0.73)

---

## 🏗️ Architecture

Built on top of UrsoNet (ResNet50 backbone):
- **Location branch**: Gaussian NLL loss with log-variance output for uncertainty
- **Orientation branch**: Soft classification over 32,768 bins with MC Dropout uncertainty decomposition

## 📁 Dataset Preparation

### Step 1 — Download SPEED

Download the official SPEED dataset from the
[ESA Kelvins Portal](https://kelvins.esa.int/satellite-pose-estimation-challenge/)
and place the raw files as follows:

```
datasets/
└── speed/
    ├── images/
    │   ├── train/        # Synthetic training images (provided by SPEED)
    │   ├── test/         # Synthetic test images    (provided by SPEED)
    │   ├── real/         # Real images for OOD evaluation (provided by SPEED)
    │   └── real_test/    # Real images for submission     (provided by SPEED)
    └── train.json        # Official annotation file       (provided by SPEED)
```

### Step 2 — Generate Dataset Splits

Run the provided split script to generate stratified train / val / test subsets:

```bash
python split_Speed.py
```

This script reads `train.json` and applies **stratified sampling** (7 : 2 : 1)
across two image domains (simple background: first 6 000 images;
complex background: last 6 000 images), producing:

```
datasets/
└── speed/
    ├── train_no_val.json   # Training split   — 8 400 images (70%)
    ├── val.json            # Validation split — 2 400 images (20%)
    └── my_test.json        # Test split       — 1 200 images (10%)
```

> 💡 The split uses `random.seed(42)` so results are fully reproducible.
> You can adjust the ratio by editing the `train_ratio` and `val_ratio`
> arguments in `split_Speed.py`.

### Final Directory Structure

```
datasets/
└── speed/
    ├── images/
    │   ├── train/
    │   ├── test/
    │   ├── real/
    │   └── real_test/
    ├── train.json          ← from SPEED official
    ├── train_no_val.json   ← generated by split_Speed.py
    ├── val.json            ← generated by split_Speed.py
    ├── my_test.json        ← generated by split_Speed.py
    ├── real.json           ← from SPEED official
    └── real_test.json      ← from SPEED official
```

## 🔍 Usage

All configurations are set directly in the `Args` class inside
`pose_estimator.py` — **no command-line arguments needed**.
Edit the relevant fields and run:

```bash
python pose_estimator.py
```

---

### 📋 Command Reference

#### 🔧 `train` — Train the model

```python
command    = "train"
dataset    = "speed"
weights    = "imagenet"   # 'imagenet' | 'coco' | 'last' | path to .h5
epochs     = 96
batch_size = 2
```

Trains on `train_no_val` split, validates on `val` split.
Checkpoints are saved to `models/logs/`.

---

#### 📊 `evaluate` — Evaluate pose estimation accuracy

```python
command = "evaluate"
weights = "models/logs/speed20260413T1059/weights_best.h5"
```

Evaluates on the `my_test` subset and reports:
- Location Error (m)
- Orientation Error (deg)
- ESA Score

---

#### 🖼️ `test` — Visualize predictions

```python
command = "test"
weights = "models/logs/speed20260413T1059/weights_best.h5"
```

Runs detection on `my_test` subset and displays visual results for 10 images.

---

#### 🌍 `extract_ood` — OOD Uncertainty Evaluation on Real Images

```python
command    = "extract_ood"
mc_dropout = True
mc_samples = 10            # Increase for more stable estimates
```

Runs MC Dropout inference on `datasets/speed/images/real/`.
Outputs `real_ood_uncertainty.csv` with per-image metrics:

| Column | Description |
|--------|-------------|
| `Loc_Error(m)` | Position estimation error |
| `Ori_Error(deg)` | Orientation estimation error |
| `Loc_Epistemic_Unc_X/Y/Z` | Per-axis location uncertainty |
| `Ori_Entropy` | Predictive entropy (total uncertainty) |
| `Ori_Expected_Entropy` | Aleatoric uncertainty |
| `Ori_Mutual_Info` | Epistemic uncertainty (MI) |

---

#### 📤 `submit` — Generate ESA submission file

```python
command = "submit"
weights = "models/logs/speed20260413T1059/weights_best.h5"
```

Generates a submission file compatible with the ESA Pose Estimation Challenge format.
